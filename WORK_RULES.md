# WORK_RULES.md — Даталоггер ANENJI на ESP8266 с SD

> Инструкция для ChatGPT Work. Актуальна для репозитория `nurgaliev-azat/ESP8266-SD-datalogger-for-anenji-hybrid-inverter`.

## Контекст
Wemos D1 mini / ESP8266, Modbus, SD-карта, веб-панель, энергетическая история и NTP.

## Специфические правила
Сохранять совместимость GPIO D4–D7 и режимов загрузки ESP8266; оберегать SD-архив и EEPROM/CRC16 при обновлениях. Не менять протокол инвертора и расчёт энергетических показателей без проверки. Обрабатывать отсутствие сети, NTP, инвертора и карты без блокировки устройства.

## Минимально необходимые проверки
Проверка компиляции ESP8266, подключения SD, Modbus, переключения RU/EN, сохранения настроек и корректности истории с пустыми интервалами.

## Общие принципы экономии Work
1. Обсуждать требования в обычном чате; в Work передавать согласованный пакет изменений.
2. Сначала читать `PROJECT_STATE.md`, README и только относящиеся к задаче файлы.
3. Сохранять архитектуру, не делать несвязанный рефакторинг и не плодить агентов.
4. Сначала целевые тесты, затем необходимые интеграционные и релизные проверки. Не повторять успешные проверки без причины.
5. Не включать опасные операции, внешние публикации и платные сервисы без явных полномочий.
6. Фиксировать только подтверждённые результаты; не путать документацию с успешным тестом.
7. После этапа кратко сообщить: изменения, проверки, проблемы, готовность релиза; актуализировать `PROJECT_STATE.md`.
8. Корректность, безопасность и совместимость имеют приоритет над экономией лимитов.
